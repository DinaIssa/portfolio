Yarn Craft API

A learning project for a crochet platform, exploring REST APIs, database design, and backend structure with Node.js, Express, and PostgreSQL. It models users, categories, products, carts, and orders, and protects routes with JWT authentication.

مشروع تعلّم لمنصة كروشية، بستكشف فيه REST APIs وتصميم قواعد البيانات وهيكلة الباك إند باستخدام Node.js وExpress وPostgreSQL. فيه المستخدمين والتصنيفات والمنتجات والسلة والطلبات، وبيحمي المسارات بتسجيل دخول JWT.

Node.jsExpressPostgreSQLTypeORMJWT

Currently in development. Details and features will be updated as the project grows.
